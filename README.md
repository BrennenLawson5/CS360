# CS360

For this project, I created Shed-It, which is a weight-tracking android app. The goal of the app was to give users a simple way record their weight and review their weight changes over time. The main user need I focused on was keeping the app straighforward. There doesn't need to be unnecessary screens and clutter if users are going to use this app just to track their weight. 

The app needed several screens to support the users needs, including a login/create account screen, dashboard, add weight screen, goal weight screen, history screen, and SMS permission screen. I kept the design consistent so that users could understand where they were in the app and what action to take next. The dashboard was especially important because it serves as the central place for the entire app. From there, you can see current weight, goal weight, and many navigation options. 

When I was coding the app, I worked through it step by step instead of trying to build everything at once. I started with the UI, then connected to the login system, database, weight entries, history grid, update/delete functions, and SMS permission handling. I was able to test each part of the app as I added them which made it easier for me to find problems. I tested the app by using the Android Emulator, which is super useful because it helps you see what your app is like and how it functions at the current stage of development. 

I struggled a bit with connecting the UI screens to the database and making sure the saved information showed up in the right places. It made me really think about how the user's actions moved through the app, especially when adding, updating, and deleting entries.
